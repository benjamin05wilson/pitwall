# Retained offline evidence

All artifacts are from the local macOS arm64 readiness run, not historical F1 predictions. Circuit parameters and generic rival strategies drive the recommendation; the stint plot uses authored synthetic observations. No weights, Rust extension or Torch were installed.

- `manifest.json`, `recommendation.json`, `transcript.txt`, `kalman.json` and `synthetic-stint.png`: generated by `python scripts/offline_demo.py` at source commit `8a06bcfca1efe4bba3a184143a8920187e01d78e`. The manifest records exact inputs, seeds, environment, fixture hashes, metric definitions and timing scope. Only socket connections are disabled in this standalone run; dependencies were installed beforehand.
- `strategy.png` and `walkthrough.webm`: real browser capture at source commit `81b5887705643798a1d662153cd85c1d321886a2`, using Node 24.18.1, Playwright 1.63.0, and the same local Python environment. The media manifest is authoritative for the installed browser-tool version.
- `pytest.txt`: core source from `8a06bcf`, 51 passed and 5 skipped in one local run. Skips are one Torch module, three explicitly opt-in network tests, and one missing-native parity test. One Starlette/httpx deprecation warning remains; requests succeeded.
- `wheel-check.txt`: rebuilt wheel at `81b5887`, installed with no dependency downloads into a temporary repository-local target. Isolated Python loaded priors from that target, not the source tree. This checks Python resource packaging, not web assets in a wheel.

Reproduce browser media after building the frontend:

```bash
PITWALL_RECORD=1 PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" npm test --prefix web -- --grep 'no weights'
```

The roughly eleven-second recording shows loading, the podium recommendation with the optional heatmap unavailable, then selection of `robust` and a refreshed recommendation. The winning plan happens to stay the same for these inputs. Four-second pauses make each result readable; they are presentation dwell time, not correctness waits. There is no narration or edited UI. Screenshot and a frame after the objective change were visually inspected.

The full browser suite passed all three tests locally after replacing a timing-dependent race test with explicitly controlled response ordering. The test now renders the new objective, releases the obsolete response, flushes response/render work, then confirms the new result remains. An earlier Linux CI run passed the first two browser tests and failed the timing-based third test; remote confirmation of the replacement is the parent's responsibility. The parent reported the earlier core commit passed Linux/Windows Python 3.11/3.12. These reports do not stand in for final-commit CI.
